# 講義範本系統 · Handout Templates

立霖國文的講義分三種模式，全部使用 A4 直式（794×1123px @96dpi），共用 `handout.css`。

| 模式 | 檔案 | 頁數 | 用途 |
|---|---|---|---|
| **深度閱讀 · 親情橋樑** | `定風波.html` | 4 頁 | 課文 + 導師旁白 + 述情詞彙 + 親子討論題。週末家庭作業型，強調人生反思。 |
| **課文講義** | `課文-愛蓮說.html` | 5 頁 | 文本帶注 + 重點整理 + 重要考點 + 習題演練。一般授課主力。 |
| **會考總複習** | `會考總複習-虛詞之.html` | 4 頁 | 主題地圖 + 延伸連結 + 陷阱辨析 + 習題演練 + 答題卡。考前衝刺。 |

## 共用樣式 `handout.css`

包含所有頁面元素：封面 (`.cover`)、內頁 head/title (`.pg__`)、課文塊 (`.original`、`.gloss-text`)、分析框 (`.anablock`)、重點 (`.keypoints`)、導師旁白 (`.mentor-voice`)、述情詞彙 (`.chip`)、親子討論題 (`.dialogue`)，以及課文／總複習新增的：

- `.exam-point` — 考點卡（6 種分類標籤：字音／字形／修辭／文意／文常／虛詞）
- `.practice` — 練習題（單選／短答／難度星級／答題格）
- `.usage-grid / .usage-card` — 用法地圖（如「之」字七用法）
- `.crossref` — 橫向／縱向連結（與其他考點、其他課文）
- `.answer-strip` — 深色答題卡 + 解析

## 怎麼用

複製一份範本，替換以下欄位即可：

1. **封面**：series（系列名）、lesson 編號、title（課文/主題名）、quote（金句）、poet（作者/標籤）、sub（封面副標）、authoring meta
2. **重點頁**：四象分析、key points、mentor voice
3. **考點頁**：每張 `.exam-point` 卡的 tag、title、example、desc、mnemonic
4. **習題頁**：每張 `.practice` 卡的題型、難度、題幹、選項、答案

## 設計準則檢核（v2.0 講義必備）

每份新講義產出前打勾：

- [ ] 封面有書法字標題（用文字暫代或圖檔）
- [ ] 內頁有 MentorVoice（人生導師連結到當代）
- [ ] 述情詞彙至少 3 個（如果是深度閱讀類）
- [ ] 親子討論題（深度閱讀類封底必備）
- [ ] 考點卡至少 4 張（課文 / 會考類）
- [ ] 習題演練含答案 + 解析（不能只給題不給答）
- [ ] 文字佔比 ≤ 60%，留白勇敢
- [ ] 不超過 3 級字重 / 4 種色彩同畫面
