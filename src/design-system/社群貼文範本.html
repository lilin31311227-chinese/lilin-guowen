圖框安全留白與裁切規則

每張版型外圍的 金色 L 型角標 標示「實際裁切邊」（bleed line）—— 上稿時對齊此邊。
內側的 虛線框 為「安全留白」，文字與 Logo 必須收在此線內，避免被 IG / FB 自動裁切。

實際稿件尺寸： IG 貼文 1080×1080　 IG 限動 1080×1920　 FB 封圖 1200×630　 LINE OA 1040×520
安全留白比例： 上下左右各保留外邊 8%（IG 約 86 px / FB 約 50 px / LINE 約 40 px）
輸出建議： 印刷 sRGB / 數位 sRGB · 72 dpi · PNG（含書法字時不壓縮）or JPEG q ≥ 90

使用提醒 · 文案三問

每張貼文發出前，回答品牌規範要求的審稿三問：
① 孩子讀到，他會覺得 被尊重 還是被擺布？　② 家長讀到，他會 鬆一口氣 還是被催促？　③ 把所有「！」和「保證」拿掉，這則文案還站得住嗎？
三題任一題答案是負面的——重寫。完整守則請見 docs/templates/COPYWRITING_KIT.md §9。
