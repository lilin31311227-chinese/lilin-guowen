## 0. 為什麼有 v2.0

v1.0 已建立「素養教學領航者」的視覺與語氣骨架，但市場上的競爭者也都在喊素養。v2.0 的差異化轉向：

| 維度 | v1.0 | v2.0（疊加） |
|------|------|------|
| 主敘事 | 我教你考試/素養 | 我陪你長大，也陪你的家重新連線 |
| 服務對象 | 學生（家長付費） | **學生 × 家長 雙軌** |
| 核心承諾 | 分數 + 邏輯思考 | 分數 + 思考 + **生命指引 + 家庭溝通** |
| 商業壁壘 | 教學方法 | 教學方法 + **情感連結 + 家庭支持網路** |

> **品牌一句話**：在分數之上、家庭之內，我是那位能被信任的人生導師。

## 1. 雙引擎品牌哲學

### 1.1 引擎 A：人生導師（Life Mentor）
**文學是載體，不是知識庫。** 導師的角色是提供多維度視角，陪伴學生在升學壓力的縫隙中尋找意義。

- 不給標準答案，給可選擇的可能
- 不說教，用文本喚醒
- 不過度親近，用尊重距離傳遞被理解感

### 1.2 引擎 B：親情橋樑（Family Bridge）
**修復家庭溝通是國文老師的隱形產品。** 課堂上引發的反思 → 家庭餐桌上的對話。

- 教師後台「課堂觀察反饋」=> 家長端微型 CRM 觸點
- 互動式聯絡簿 => 親子討論題
- 體驗活動 => 共同記憶錨點

### 1.3 兩引擎與 v1.0 主敘事的關係
```
v1.0 「素養教學領航者」      ← 學科專業底氣
    ↓
v2.0 引擎 A「人生導師」       ← 對學生的深度承諾
v2.0 引擎 B「親情橋樑」       ← 對家長的差異化價值
    ↓
品牌護城河 = 三者交集（無人能同時做到）
```

## 2. 受眾雙軌設計 Dual-Track Audience

### 2.1 學生軌（Student Track）
- 心理需求：被理解、被陪伴、找方向、解壓力
- 介面語氣：**平起平坐的對話者**（嚴禁上對下說教）
- 主色調：橋樑連結色（湖青 `--bridge-teal` / 苔綠 `--bridge-sage`）
- 主要載體：IG、匿名信箱、體驗活動、限動互動

### 2.2 家長軌（Parent Track）
- 心理需求：被卸責、被支持、要工具、要安心
- 介面語氣：**理解與卸責的支持者**（嚴禁焦慮綁架）
- 主色調：人生導師暖色（赤茶 `--mentor-terracotta` / 琥珀 `--mentor-amber`）
- 主要載體：FB 長文、LINE 推播、親師生互動門戶、月報

### 2.3 雙軌動線範例
```
網站首頁 Hero
   ↓
DualTrackEntry 元件（卡片左右分流）
   ├─ [湖青卡] 學生入口 → /for-students
   └─ [赤茶卡] 家長入口 → /for-parents
```

## 5. 核心新元件 v2.0 Components

> 程式碼位於 `src/components/brand/`，可直接 import 使用。

### 5.1 `<MentorVoice>` 導師旁白塊
用途：講義側邊欄 / 文章插入 / 課程卡內，由「人生導師」拋出與學生生命經驗連結的反思。

```tsx
<MentorVoice classicReference="蘇軾《定風波》">
  在現代社會中，我們經常面臨各種期待。你認為我們應該對誰展現最大的忠誠？
  如果是對自己忠誠，那意味著你必須承擔什麼樣的責任？
</MentorVoice>
```

### 5.2 `<FamilyBridgeCard>` 親情橋樑互動卡
用途：教師後台 → 家長端的「課堂觀察反饋」微型 CRM。

```tsx
<FamilyBridgeCard
  teacherName="立霖"
  observationDate="2026-05-12"
  studentContext="今日討論《紅樓夢》家族衰敗議題，孩子展現非常深刻的同理心..."
  classicConnection="《紅樓夢》第七十四回"
  parentSuggestion="建議今晚可與孩子聊聊對未來挑戰的看法，並給予肯定。"
/>
```

### 5.3 `<DialoguePrompt>` 親子討論題卡
用途：每週講義最後一頁、聯絡簿、LINE 週末破冰話題。

```tsx
<DialoguePrompt
  weekTopic="朱自清《背影》—— 看見父母不曾被看見的付出"
  prompt="請在接下來的三天內，觀察並寫下一個父母為你付出、但你過去未曾留意的微小細節..."
  observationGuideline="家長也請在聯絡簿欄位回饋當時做這件事的想法。"
/>
```

### 5.4 `<EmotionChip>` 述情詞彙標籤
用途：情緒詞彙擴充教材、匿名信箱情緒選擇、心情日誌。

```tsx
<EmotionChip type="melancholy" />  {/* 鬱 · 惆悵 */}
<EmotionChip type="hope" />        {/* 望 · 懷想 */}
```

### 5.5 `<DualTrackEntry>` 雙軌動線入口
用途：首頁 Hero 下方、LINE 加入好友後初始問卷、登入頁。

### 5.6 `<ExperienceCard>` 體驗活動卡
用途：活動報名頁、社群推廣、家長端電子報。內建五感標籤系統。

```tsx
<ExperienceCard
  title="自然 · 輕觸之旅"
  subtitle="親子五感體驗日"
  duration="4 小時"
  capacity="≤20 人"
  price="$150/位"
  senses={['sight', 'sound', 'touch']}
  description="靜觀漫步、自然書寫、藝術共創、共食共備..."
  classicQuote={{ text: '采菊東籬下，悠然見南山。', source: '陶淵明' }}
/>
```

### 5.7 `<VoiceToneMatrix>` 語氣對照表
用途：品牌指南頁、新進師資培訓、社群文案 SOP。

## 6. 文宣敘事策略 Narrative Strategy

### 6.1 從「販賣焦慮」到「提供解方」的典範轉移

| 維度 | ❌ 傳統補習班 | ✅ 立霖 v2.0 |
|------|------|------|
| 倒數恐嚇 | 距離學測剩 87 天！ | 在分數抵達之前，你已經抵達自己 |
| 比較焦慮 | 不補習就會輸 | 不需要打敗誰，只需要找到你自己 |
| 榜單轟炸 | 滿級分名單長串 | 一位學生面對挫折的真實成長故事 |
| 價格訴求 | 限時優惠！搶名額！ | 高單價，是因為改變的不只是分數 |

### 6.2 家長端文案核心：理解與卸責
**卸責 ≠ 卸下責任，而是減輕「自責」。**

範例：
- 「我們懂您的欲言又止，那些不知如何開口的關心，讓文學的溫柔替您說。」
- 「他現在的沉默不是叛逆，他只是在龐大的世界中尋找自己的座標；請給我們一個機會，陪他讀懂世界，也讓您重新讀懂他。」

### 6.3 學生端文案核心：平起平坐
- 「分數只是檢驗知識的過程，你擁有什麼樣的人生才是最終的目的。」
- 「在孔孟老莊的千言萬語中，總有一句能溫柔地接住現在搖搖欲墜的你。」

### 6.4 寫作公式
1. **同理 → 重新框架 → 邀請**（不是說服）
2. 一段文案只承擔一個情緒任務
3. 引用古典詩文要負責任：給出處 + 給現代轉譯
4. 嚴禁「！！！」「保證」「絕對」「超划算」

## 7. 講義 / 教材 v2.0 設計準則

### 7.1 認知負荷三原則
1. **留白勇敢**：頁面文字佔比 ≤ 60%
2. **層級清晰**：主標 / 副標 / 內文 / 旁白，視覺重量差異 ≥ 1.5x
3. **不超過 3 級子標題**

### 7.2 必備版面區塊
每份講義至少包含：
- 主文本（傳統解析）
- 1 個 `<MentorVoice>` 導師旁白（連結當代議題）
- 1 個情緒詞彙擴充欄位（最少 3 個 `<EmotionChip>`）
- 1 個 `<DialoguePrompt>` 親子討論題（封底）

### 7.3 紙張規格
- 內頁：80gsm 雪面道林紙（不反光、有溫度）
- 封面：120gsm 凝雪紙 / 瑞典輕塗紙
- 印刷：四色不打底（保留紙張肌理）、燙金限封面 Logo

## 8. 實體活動體驗系統

### 8.1 兩大旗艦活動

**活動 A：自然 · 輕觸之旅**
- 對象：親子（國高中生 + 家長）
- 時長：半日 4 小時（含共食）
- 人數：≤20 人
- 費用：$150 / 位（含午膳，不含車費）
- 五感焦點：視 / 聽 / 觸
- 機制：靜觀漫步 → 自然書寫 → 藝術共創 → 共食共備

**活動 B：動身體 · 樂溝通**
- 對象：親子（國中生 + 家長）
- 時長：1 小時
- 人數：≤20 人
- 費用：$1000
- 機制：律動遊戲 → 文學戲劇情境角色扮演 → 反思圈

### 8.2 活動設計原則
- 永遠在「語言之外」設計溝通機制（肢體 / 五感 / 共創）
- 永遠有「文學錨點」（一句詩、一篇文、一個典故）
- 永遠以「無批判分享」收尾，禁止指導與糾正

## 9. 數位陪伴系統佈局

### 9.1 LINE 官方帳號（私域）
- 加好友自動分流：學生 / 家長 / 年級
- 學生：每週日晚「導師箴言」+ 月底匿名信箱提醒
- 家長：每週五下午「親子破冰話題」+ 月初課堂觀察月報

### 9.2 Instagram（學生為主）
- 限動：每日「微反思」（投票 / 問答 / 滑動條）
- 貼文：金句卡片（每週 3 篇）+ 學長姐心聲（每週 1 篇）
- 視覺：高度一致的紙莎草米 + 藍金配色

### 9.3 Facebook（家長為主）
- 長文：每週 1 篇心靈專欄（教養 × 文學）
- 私密社團：家長互助圈，每月 1 次線上講座

### 9.4 各平台 KPI 對照表
| 平台 | 主受眾 | 核心 KPI |
|------|------|------|
| LINE | 學生 + 家長 | 封鎖率 ≤ 5%、訊息點擊率 ≥ 15% |
| IG | 學生 | 限動完播率 ≥ 50%、貼文珍藏數 |
| FB | 家長 | 長文分享數、社團活躍度 |

## 10. 品牌物件產出檢核清單 v2.0

每次新物件產出前，逐項打勾：

- [ ] **v1.0 視覺檢核**：色彩 / 字型 / Logo / 構圖 / 文案語氣（見 `BRAND_GUIDELINES.md` 第 13 節）
- [ ] **雙軌定位**：此物件主要對學生說還是對家長說？語氣是否對應？
- [ ] **人生導師訊號**：是否至少傳達一個「思考的可能 / 生命的可能」？
- [ ] **親情橋樑訊號**：是否為親子互動留下種子（討論題 / 觀察任務 / 共讀引子）？
- [ ] **嚴禁焦慮綁架**：是否出現「倒數 / 落後 / 保證」字眼？
- [ ] **誠品櫥窗測試**：放在誠品書店櫥窗仍然合理嗎？
- [ ] **沉默測試**：把所有文字遮住，視覺仍能傳遞品牌氣質嗎？
