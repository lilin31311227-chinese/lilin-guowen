## 1. 品牌核心 Brand Core

### 1.1 品牌定位
**素養教學領航者 · 家長與孩子的溝通橋樑**

立霖國文不是一間「補習班式」的家教，而是「以古典智慧引導人生方向」的素養教育品牌。我們販售的不是分數，而是「終身受用的思考能力」。

### 1.2 品牌主張（Slogan）
- **主標語**：人生沒有 Google，但有經典可循。
- **副標語**：不只提升分數，更引導人生方向。
- **延伸句**：帶你讀懂文章邏輯，寫出生命厚度。

### 1.3 品牌人格 Brand Personality
| 維度 | 是 | 不是 |
|------|------|------|
| 氣質 | 沉穩、典雅、溫潤 | 浮誇、廉價、嘈雜 |
| 語氣 | 引導、信任、像長輩 | 命令、推銷、像業務 |
| 視覺 | 東方古典 × 現代極簡 | 卡通插畫、補習班紅黃 |
| 高度 | 高單價、高價值、高承諾 | 低價競爭、優惠轟炸 |

> 一句話判斷：「這個物件放在誠品書店的櫥窗合理嗎？」如果不合理，就不對。

## 2. Logo 系統

### 2.1 主要資產
| 檔名 | 用途 |
|------|------|
| `public/images/logo.png` | 標準 Logo（彩色，淺底使用） |
| `public/images/立霖國文書法字 去背.png` | 書法字標準字（深底用，需反白濾鏡） |
| `public/images/網站圖標.png` | 方形圖標（社群頭像、favicon） |
| `src/app/icon.png` | 瀏覽器 icon |

### 2.2 使用規則
- **最小尺寸**：書法字標準字 ≥ 高度 32px；方形圖標 ≥ 24px。
- **安全空間**：Logo 四周保留至少「立」字高度的留白，禁止裁切或遮擋。
- **深底反白**：在深海軍藍底（`#0A1A35`、`#1a365d`）上使用書法字時，套用 `filter: brightness(0) invert(1)` 轉為純白。
- **禁止事項**：
  - ❌ 變形拉伸、改色、加陰影、加描邊
  - ❌ 旋轉超過 5°（除非作為裝飾性背景紋理）
  - ❌ 與其他字標並列時，不得小於對方視覺重量

## 3. 色彩系統 Color System

### 3.1 主色 Primary Palette（三色定調）

| 角色 | 名稱 | HEX | CSS 變數 | 使用場景 |
|------|------|------|------|------|
| 主色 | 深海軍藍 Navy | `#1a365d` | `--navy` | 標題、主文字、深底背景 |
| 強調 | 晨曦金 Gold | `#d69e2e` | `--gold` | CTA、徽章、強調、分隔線 |
| 底色 | 紙莎草白 Cream | `#faf5ef` | `--cream` | 全站背景、卡片留白 |

### 3.2 主色階梯 Tonal Steps

```
Navy:  #0f2744 (dark) → #1a365d (base) → #2c5282 (light)
Gold:  #b7791f (dark) → #d69e2e (base) → #ecc94b (light)
Cream: #faf5ef (base) → #f5e6d3 (dark)
```

### 3.3 Hero 戲劇性深色 Hero Drama Tones
專用於主視覺 / 封面 / 海報主圖，營造「夜空 × 古典」氣場：

| 用途 | HEX |
|------|------|
| Hero 背景基底 | `#0A1A35` |
| Hero 漸層中段 | `#0d2341` |
| Hero 漸層深處 | `#071428` |
| Hero 金色重點（暖光） | `#F59E0B` / `#FBBF24` / `#FCD34D` |

> Hero 漸層方向固定：`bg-gradient-to-br from-[#0A1A35] via-[#0d2341] to-[#071428]`

### 3.4 語意輔色 Semantic Accents
僅用於「四大教學領域」識別與資料標籤，不可用於主品牌色：

| 領域 | 主色 | 漸層 | 使用情境 |
|------|------|------|------|
| 閱讀理解 | Blue | `from-blue-400 to-blue-500` | 邏輯、分析 |
| 寫作表達 | Emerald | `from-emerald-400 to-teal-500` | 創意、成長 |
| 古文素養 | Violet | `from-violet-400 to-purple-500` | 經典、智慧 |
| 考試策略 | Orange | `from-orange-400 to-amber-500` | 行動、戰略 |

### 3.5 配色比例（70/20/10 法則）
- **70%** 紙莎草白 / 深海軍藍（背景與大面積結構）
- **20%** 晨曦金（強調、CTA、分隔）
- **10%** 語意輔色 / 中性灰（資訊識別）

> ⚠️ 禁止：紅色（補習班廉價感）、螢光色、純黑（用 `#0A1A35` 取代）。

## 4. 字型系統 Typography

### 4.1 字型家族
- **中文主字**：`Noto Sans TC`（官網與所有數位物件）
- **中文備援**：`Microsoft JhengHei`, `PingFang TC`
- **英文/數字**：`Geist Sans`, Arial
- **書法視覺**：使用「立霖國文書法字 去背.png」作為圖片資產，不另尋字型替代

### 4.2 字重與層級
| 層級 | 字重 | 桌面尺寸 | 手機尺寸 | 顏色 |
|------|------|------|------|------|
| H1 主標 | 700 | 56px (3.5rem) | 36px | Navy 或白色（深底） |
| H2 區塊標 | 700 | 40px (2.5rem) | 30px | Navy |
| H3 卡片標 | 700 | 24px | 20px | Navy |
| 副標 / Lead | 400 | 20px | 18px | Navy-light |
| Body | 400 | 16px | 16px | Navy |
| Caption | 500 | 14px | 14px | Navy-light |
| Trust Badge | 500 | 14px | 13px | Gold |

### 4.3 排版原則
- 行高：標題 `1.15`–`1.25`；內文 `1.6`–`1.75`（中文需要呼吸感）
- 字距：標題 `tracking-tight`；徽章 `tracking-wider`
- 重點突出：用「金色描底字」(`bg-clip-text bg-gradient-to-r from-amber-300 via-amber-400 to-yellow-300`)，不要加底線、不要全大寫
- 禁止：全形空格混排、明體 + 楷體混用、超過 3 種字重同畫面

## 5. 視覺語彙 Visual Language

### 5.1 三個必備元素（每個物件至少出現一個）
1. **書法字 / 古典筆觸**：傳達「典雅、有內涵」
2. **金色細線 / 漸層光點**：傳達「珍貴、有靈光」
3. **深藍夜空 / 紙莎草米色**：傳達「沉穩、有底蘊」

### 5.2 東方裝飾元素 Oriental Motifs

可重複使用的 SVG 語彙（網站 `HeroSection.tsx` 內建）：

- **祥雲紋（Xiangyun）**：用流暢曲線勾勒，`stroke-width: 1–1.5`，`opacity: 0.15–0.25`，置於四角作背景。
- **古籍 / 卷軸 / 竹簡圖示**：線稿風格、金色描邊、低不透明度浮動。
- **渾天儀（Armillary Sphere）**：金色漸層橢圓環疊加，用於主視覺中心或大型物件背景，象徵「典籍智慧 × 宇宙觀」。
- **金色粒子**：直徑 4–10px、模糊 0.5–1px、不透明度 0.5–0.8，散落於畫面增加靈光感。

### 5.3 構圖原則 Composition

| 原則 | 說明 |
|------|------|
| 對稱中軸 | 重要物件（人像、Logo、標題）置於黃金分割點或中軸線 |
| 留白呼吸 | 物件四周保留 ≥ 8% 安全留白，不擠迫 |
| 縱向韻律 | 多文字物件採用「金色細線分隔」而非框線 |
| 光源從上 | 漸層由上偏暖、由下偏深，模擬日出/燭光 |

### 5.4 圖片處理
- 人像：去背後加金色光暈 `drop-shadow(0 0 30px rgba(251,191,36,0.3))`
- 古典素材：套用 `mix-blend-mode: overlay` 與深藍底融合
- 禁止：使用補習班式紅黃 banner、誇張 Emoji 表情、低解析度截圖

## 6. 元件規範 Component Specs

### 6.1 按鈕 Button

**Primary（主要 CTA）**
- 背景：金色漸層 `from-amber-400 to-amber-500`
- 文字：`#0A1A35`（深海軍藍）
- Padding：`px-8 py-4` 或 `0.75rem 1.5rem`
- 圓角：`rounded-lg`（0.5rem）
- 陰影：`shadow-lg shadow-amber-500/30`
- Hover：`-translate-y-0.5` + 陰影加深

**Secondary（次要）**
- 背景：透明
- 文字 / 邊框：Navy 或金色（依底色）
- Hover：填色翻轉

### 6.2 卡片 Card
- 背景：白色（淺底）或 `bg-{色}-500/10` 半透明 + `backdrop-blur-sm`（深底）
- 圓角：`rounded-xl`（1rem）或 `rounded-2xl`（1.5rem 用於主要區塊）
- 邊框：深底用 `border border-{色}-400/40`
- 陰影：`card-shadow-md`（`0 4px 16px rgba(26,54,93,0.1)`）
- Hover：`-translate-y-2` + 陰影 `card-shadow-lg`

### 6.3 徽章 Trust Badge
- 結構：`金色圓點 icon + 文字`
- 背景：`bg-amber-400/10` + `border border-amber-400/30` + `backdrop-blur-sm`
- 圓角：`rounded-full`
- 用法：放在主標題上方，宣告「身分 / 認證 / 數據」

### 6.4 引言區 Blockquote
- 背景：Navy 深底色
- 文字：Cream
- 出處：金色，靠右，前綴 `—`
- 範例：`「教育不是注滿一桶水，而是點燃一把火。」— 葉慈`

### 6.5 分隔線 Divider
不使用實心線，改用：
- 金色漸層細線：`h-[1px] bg-gradient-to-r from-transparent via-amber-400/60 to-transparent`
- 點狀 `dash-array: 20 10`（裝飾用）

## 7. 間距 / 圓角 / 陰影 系統

### 7.1 間距 Spacing（8 點網格）
- 基本單位：`4px / 8px / 16px / 24px / 32px / 48px / 64px / 96px / 128px`
- 區塊垂直 padding：桌面 `py-20 lg:py-28`；手機 `py-12`
- 卡片內距：`p-6` 或 `p-8`

### 7.2 圓角 Radius
| 用途 | 數值 |
|------|------|
| 小元素（按鈕、徽章 icon） | `rounded-lg`（0.5rem） |
| 卡片 / 輸入框 | `rounded-xl`（1rem） |
| 大區塊 / 圖片框 | `rounded-2xl`（1.5rem） |
| 圓形（人像、徽章、標籤） | `rounded-full` |

### 7.3 陰影 Shadow（已封裝為 utility）
```
.card-shadow-sm   → 0 2px 8px  rgba(26,54,93,0.08)  — 輕微浮起
.card-shadow-md   → 0 4px 16px rgba(26,54,93,0.10)  — 預設卡片
.card-shadow-lg   → 0 8px 24px rgba(26,54,93,0.12)  — Hover 強調
.card-shadow-hover → transition + translateY(-2px)   — 互動回饋
```
> 陰影顏色一律以 Navy 為基底，禁止使用純黑陰影。

## 8. 動效原則 Motion

| 動效 | 用途 | 時間 / 緩動 |
|------|------|------|
| `spin-very-slow` | 渾天儀外環 | 60s linear infinite |
| `spin-slow-reverse` | 渾天儀中環（反向） | 45s linear infinite |
| `spin-medium` | 渾天儀內環 | 30s linear infinite |
| `float-slow` | 漂浮古籍 / 卷軸 | 8s ease-in-out infinite |
| `pulse-slow` | 金色粒子閃爍 | 4s ease-in-out infinite |
| Hover lift | 卡片 / 按鈕 | 200–300ms ease |

**節制原則**：一個畫面同時運行的動效 ≤ 3 種；動效服務「典雅 / 智慧 / 從容」，禁止彈跳、抖動、霓虹閃爍。

## 9. 文案語氣 Voice & Tone

### 9.1 三個關鍵詞
**引導 · 信任 · 不浮誇**

### 9.2 語氣對照
| 場景 | ✅ 這樣寫 | ❌ 不要這樣寫 |
|------|------|------|
| 招生 CTA | 預約免費診斷諮詢 | 立刻搶名額！手刀報名！ |
| 戰績 | 多位學生從及格邊緣躍升 A++ | 保證 A++ ！100% 上榜！ |
| 價格 | 高單價，是因為改變的不只是分數 | 超划算！每堂只要 $$$ |
| 課程價值 | 帶你讀懂文章邏輯，寫出生命厚度 | 包你會考國文滿級分 |

### 9.3 寫作公式
1. **痛點共鳴 → 方法論 → 成果承諾**
2. 用「你 / 孩子 / 我們」，不用「同學們、各位家長朋友」
3. 引用名人語錄要標出處（如葉慈、論語）
4. 數字用阿拉伯數字（500+ 學員、95% 滿意度）

### 9.4 標點符號
- 中文逗號頓號用全形：`，、。「」`
- 引號統一用「」，避免 ""
- 破折號用全形 `——`
- 連續標點不超過兩個（禁止「！！！」）

## 10. 應用範例 Application Templates

### 10.1 社群圖卡（IG / FB Post，1080×1080）
- 背景：Hero 深藍漸層 或 紙莎草白
- 結構：左上 Logo / 中央金色標題 / 右下角立霖落款
- 必備：祥雲紋裝飾 + 金色細線分隔
- 字級：標題 ≥ 64px，內文 ≥ 28px

### 10.2 海報 / 傳單（A4 直式）
- 上 1/3：Hero 主視覺（深藍 + 渾天儀 + 老師形象照）
- 中 1/3：金色細線分隔 + 課程主題 + 三大特色卡片
- 下 1/3：CTA + 聯絡方式 + Logo
- 紙張：建議印於米色道林紙或進口紙莎草紙質感紙

### 10.3 簡報模板（16:9）
- 封面：Hero 風格，僅放標題 + 立霖落款
- 內頁：紙莎草白底 + Navy 標題 + 金色重點劃線
- 數據頁：使用四色語意輔色作圖表
- 結尾：金色細線 + 引言 + 聯絡方式

### 10.4 名片（90×54mm）
- 正面：書法字 Logo（金色燙金）+ 深藍底
- 反面：紙莎草白 + Navy 文字 + 金色頭銜

### 10.5 教材 / 講義封面
- 上：金色細線 + 系列名稱（如「素養閱讀．第一冊」）
- 中：書法字主標題（手寫感）
- 下：立霖國文 Logo + 期數

### 10.6 Email 簽名檔
```
立霖老師 ｜ 立霖國文
素養教學領航者
人生沒有 Google，但有經典可循。
🌐 [網站] ✉ contact@lilin-guowen.tw
```
（電子簽名檔避免使用過多 emoji，金色 Unicode 飾物可保留 1–2 個）

## 12. 不該做的 Don'ts ❌

1. ❌ 使用紅色 / 螢光黃 / 純黑（除非作為內文）
2. ❌ Logo 旋轉、變形、改色
3. ❌ 加底線強調（用金色取代）
4. ❌ 圖片加廉價光暈、星光、霓虹
5. ❌ 文案用「！！！」「超划算」「保證滿分」
6. ❌ 一個畫面超過 3 種字重 / 4 種色彩
7. ❌ 使用補習班常見的卡通插畫風格
8. ❌ 把語意輔色（藍/綠/紫/橘）用於主品牌色位
9. ❌ 動效誇張彈跳、霓虹閃爍、無限自動播放音樂
10. ❌ 在低對比下放置文字（背景 vs 文字對比 < 4.5:1）

## 13. 品牌物件產出檢核清單 Checklist

每次新物件產出前，逐項打勾：

- [ ] **色彩**：是否使用 70/20/10 配色比例？是否在主色階梯內？
- [ ] **字型**：中文是否為 Noto Sans TC？標題字重是否為 700？
- [ ] **Logo**：是否符合最小尺寸與安全空間？深底是否反白？
- [ ] **視覺語彙**：是否包含「書法 / 金色 / 深藍或米色」三元素至少一項？
- [ ] **構圖**：留白是否充足？光源是否由上偏暖？
- [ ] **元件**：按鈕 / 卡片 / 徽章是否符合規範？陰影顏色是否為 Navy 基底？
- [ ] **文案**：語氣是否為「引導而非推銷」？標點是否為全形？
- [ ] **動效**（若有）：是否 ≤ 3 種同時運行？是否典雅而非浮誇？
- [ ] **無障礙**：對比度 ≥ 4.5:1？圖片有 alt？
- [ ] **誠品櫥窗測試**：放在誠品書店櫥窗合理嗎？
